# SUSTech Survival Kit｜把这几年过值

一个非官方、长期维护、面向南科大学生的公开资源与经验网站。

## 设计目标

- 长期有效：优先收录长期入口，减少一次性通知。
- 靠谱优先：政策类信息尽量指向学校官方入口；重要事实提醒核验原始来源。
- 容易维护：纯 HTML/CSS/JavaScript，不依赖数据库或构建工具。
- 适合 GitHub Pages：文件放在仓库根目录即可部署。

## 内容维护

建议每学期检查一次：

1. 学校官方入口是否变化；
2. 试用型数据库 / AI 工具是否过期；
3. 访学、报销、就业政策是否更新；
4. 外部工具是否仍然活跃；
5. 新增一条真实踩坑记录。
